# 넥서스 오토배틀러 — 최종 기획안 (v1.0)

> 스타크래프트식 운영(자원·테크·확장) + 오토체스 자동 전투 + 증강 선택 + **넥서스 이중 승리 조건**
> 본 문서의 모든 수치는 **초안**입니다. 플레이테스트로 조정하며, 근거가 없는 값은 `[확인 필요]`로 표시했습니다.
> 구현 상태: ✅ 구현됨 / 🔜 2차 / 💤 3차

## 0. 한 줄 컨셉
8명이 서바이벌로 겨루되, 매 라운드는 **1:1 자동 전투(1분 이내)**. 상대 유닛을 전멸시키거나 **상대 넥서스를 파괴**하면 이긴다. "안전하게 전멸시킬까, 넥서스를 저격할까"가 핵심 선택이다.

### 디자인 기둥
1. **내가 선택했다는 감각** — 운이 아니라 결정의 결과(빌드·정찰·저격 선언).
2. **심리전** — 정찰, 저격 선언, 위장 배치로 속고 속이기.
3. **이야기가 남는 판** — 승급·시너지 폭발·넥서스 위기·저격 성공의 순간.
4. **져도 배운다** — 패인 리포트로 탈락 이유를 명확히.

| 대전 방식 | 오토체스식 간접 대결(유닛이 자동 전투) ✅ |

### 1-1. 승리/패배 조건
- **전투 승리**: (1) 상대 필드 유닛 전원 사살 → 라운드 승리, 패자 넥서스에 피해 (2) 상대 넥서스 파괴 → 즉시 탈락.
- **게임 승리**: 최후의 1인. 30라운드까지 끝나지 않으면 넥서스 HP 순.
- **무승부**: 동시 전멸/타임오버 후 동률일 때 (피해 없음).

## 2. 라운드 흐름
`수입 정산 → (증강) → 준비 30초 → 전투(최대 60초) → 결과/패인 리포트`

### 2-1. 전투 타임라인 (1분 이내) ✅
| 구간 | 시간 | 내용 |
|---|---|---|
| 개시 | 0~3초 | 양측 보드 공개, 카운트다운 |
| 본 교전 | 3~30초 | 일반 교전 |
| 광폭화 | 30~55초 | **모든 유닛 기본 공격속도만** 매초 +10% 누적 (공격력·스킬·회복·쉴드는 불변) |
| 판정 | 55초 | 결판이 안 났을 때만 아래 순서로 판정 |
| 결과 | 55~60초 | 승패·피해량 표시 (최대 5초, 건너뛰기 가능) |

- 광폭화 계산: 25초 × 10% = +250%, 55초 시점 공속 3.5배. (초안, 이전 논의의 6%에서 플레이테스트 결과 10%로 조정)
- **회복/쉴드는 광폭화 중에도 그대로** (공속 증가에만 의존). 교착 가능성은 §10 지표로 감시.
- 승리 조건 달성 즉시 종료하므로 평균 전투는 약 30초.
- **타임오버 판정 순서**: ① 양측 유닛이 있으면 생존 유닛 가치(코스트×★배수) 합이 큰 쪽 → ② 유닛이 없거나 동률이면 넥서스 HP 비율 → ③ 그래도 같으면 **무승부**.
- 최소 피해 1 보장 (방어력으로 피해가 0이 되지 않도록).

#### 타임오버 5% 이내를 위한 장치 ✅
측정 결과(§10) 초기 타임오버 약 20~29%의 주원인은 **방패병/분쇄수의 자가 방어막이 마나 기반으로 계속 재생·누적되어 교착**되는 것이었습니다. 다음 조치로 0.8%까지 낮췄습니다.
1. **방어막 비중첩**: 방어막 스킬은 합산이 아니라 `max(현재 방어막, 스킬 수치)`로 갱신.
2. **방어막 스킬 하향**: 방패병 300→220 / 마나 50→65, 분쇄수 400→300 / 마나 55→70.
3. **피격 마나 획득 4→3** (`MANA_HIT`).
4. **전역 공격 배율 ×1.35→1.4** (초기 1.7까지 올려 보고, 전투가 16초로 너무 짧아져 1.4로 절충).
5. 마나 폭풍 이벤트에서도 방어막 계열은 마나 가속에서 제외(교착 재발 방지).
- 회복/쉴드를 광폭화에서 제외하는 기존 결정(공속 효과에만 의존)은 그대로 유지.

### 2-2. 직관성 장치 ✅
- 전투 HUD: `아군 N vs 적 N · 교전/광폭화 · 경과초/55s`, 양측 넥서스 HP·방벽 표시.
- 결과 화면: "전멸 승리 / 넥서스 파괴 / 시간 판정" 한 줄 요약 + 패인 리포트.
- 1x/2x/4x 배속, 건너뛰기.

## 3. 보드와 전투 규칙
| 항목 | 값(초안) |
|---|---|
| 보드 | **육각 타일** 7 × 8 (진영당 4행, odd-r 배열: 홀수 행이 반 칸 이동) ✅ |
| 이동 | 6방향. 같은 거리의 경로가 여러 갈래라 유닛 홀/짝마다 좌·우 경로를 번갈아 선호 → **동선 분산** ✅ |
| 이동 속도 | 기본 2칸/초 (유닛별 상이) |
| 사거리/범위 | 모두 육각 칸 수 기준 (근접 1 = 인접 칸) |
| 인구수 | 테크 1~5 단계: 4 / 5 / 6 / 8 / 10 (+증강) |
| 스킬 | 유닛당 최대 1개, 마나 시작 50%, 공격 시 +8, 피격 시 +3 |
| 공격 | 즉발(투사체 없음), 피해 = max(1, 공격력 − 방어력) |
| 전역 공격 배율 | ×1.4 (전투가 1분 안에 끝나도록 조정한 값) |
| 시뮬레이션 | 고정 틱 0.1초, 시드 고정 결정론적 → 리플레이 가능 구조 |
| 화면 | **3D(Three.js, 기본)** / 2D 전환 가능. 육각 타일·지형·공중 유닛(떠 있는 모델+그림자)·피해 숫자 표시 ✅ |

### 3-1. 타겟팅 / 유닛 AI ✅
- 기본: **공격 가능한** 가장 가까운 적 유닛을 향해 이동·공격.
- **침투 태그 유닛**과 **저격 선언 시 수비 외 모든 유닛**: 적 넥서스를 우선 목표로 이동·공격 (경로가 막히면 교전).
- 때릴 수 있는 적이 하나도 없으면 넥서스로 향합니다(예: 근접 지상 부대 vs 공중 부대).
- 유닛이 넥서스(3칸 폭 가상 육각 칸)의 사거리 안에 들어오면 직격. 근접은 넥서스 바로 앞 4칸에서 공격할 수 있습니다.

### 3-2. 공중 · 대공 (뒷문 전략) ✅
| 구분 | 규칙 |
|---|---|
| 공중 유닛 ✈ | 지상 점유·**절벽을 무시**하고 이동(별도 레이어). 지상 전열을 건너뛰어 곧바로 넥서스에 닿는다 = **백도어** |
| 지상만 공격 | 근접·중장갑(방패병, 갉이, 땅굴벌레, 분쇄수, 거신 괴수, 광전사, 수호병, 집정관, 공성전차, 불멸자)은 공중을 공격하지 못한다 |
| 공중만 공격(대공) | 대공 포병, 포자 군체, 공중 요격수: 공중 유닛에게 **×2.0** 피해, 지상은 공격 못함 |
| 제한 해제 | **광폭화(30초)부터 모든 공격 대상 제한이 풀린다** (교착 방지) |
| 공중 시너지 | 2종: 공중 체력 +15% / 3종: + 이동속도 +20%, 넥서스 피해 +40% |
| 반격 | 넥서스 기본 포탑(초당 50, 공중에게 ×1.5)이 접근한 적을 공격. 증강 "대공 포대"는 공중에 ×2 |

### 3-3. 지형 ✅
3라운드부터 중립전을 제외한 라운드의 45%에 지형이 생기며 **준비 단계에서 미리 공개**됩니다. 절벽 위에는 배치할 수 없고, 이미 놓인 유닛은 가장 가까운 빈 칸으로 자동 이동합니다.
| 지형 | 효과 |
|---|---|
| 협곡 | 중앙 3칸만 열려 있음. 지상 병력이 한곳으로 몰린다 |
| 측면 샛길 | 중앙이 절벽. 양 옆 2칸 길로만 통과 → 샛길 침투 |
| 균열 | 양쪽 가장자리 1칸만 열림. 가장자리 점령이 중요 |
| 땅굴 지대 | 가장자리에 땅굴 입구 2개. **지상 침투 유닛**이 입구에 들어가면 적 넥서스 바로 옆 출구로 순간이동 |
- **침투 태그 지상 유닛은 절벽을 넘을 수 있다**(등반).
- 공중 유닛은 모든 지형을 무시한다.

| 저격 선언 | 수비 외 모든 유닛이 넥서스로 돌격. **돌격 태세**: 넥서스 피해 ×1.25, 이동속도 ×1.15 |
| 저격 선언 패배 | 패배 피해 ×1.5 (돌격 대장은 ×1.2) |

### 4-1. 넥서스를 노리는 수단
- **공중 유닛 + 저격 선언**: 가장 확실한 뒷문. 공중 2종 이상이면 시너지(넥서스 피해 +40%)까지 붙는다.
- **침투 유닛**(그림자 요원, 땅굴벌레, 추적자): 자동 저격, 침투 시너지, **절벽 통과**, **땅굴 지대에서 순간이동**.
- **공성 유닛**(공성전차, 전함, 거신 괴수, 불멸자, 포식자, 모함): 넥서스 피해 배율 ×1.2~1.6, 공성 시너지.
- 증강: 넥서스 저격(+50%), 제공권 장악(공중 +20%), 교란 장막(적 침투 5초 지연).
- **구성에 따른 효율(§10)**: 공중이 없는 순수 지상 저격은 위험한 도박, 공중 2종 이상이면 확실한 선택지.

### 4-2. 넥서스를 지키는 수단
- **대공 유닛**을 최소 1기 확보 (공중 2배 피해). 근접 부대만으로는 공중 저격을 막을 수 없다.
- 전열 유닛으로 길 막기(수비 태그), 수비 시너지(방어력, 방벽 +600).
- 지형 활용: 협곡/균열에서는 지상 침투 경로가 좁아 수비가 쉽다.
- 증강: 방벽 발생기, 자동 수리(라운드당 6%), 반격 포탑, 대공 포대, 철옹성.
- 트레이드오프: **확장 기지**는 수입이 늘지만 넥서스 방벽 −300.

## 13. 저작권 주의
유닛·종족·넥서스 이름은 **스타크래프트의 오마주일 뿐 블리자드 IP가 아닌 자체 명칭**(연합군/군체/성역 등)으로 구성했습니다. 이미지·사운드 에셋도 외부 IP를 사용하지 않습니다. 상용 배포 전에는 세계관/네이밍/연출의 유사성 검토가 필요합니다 `[확인 필요]`.

## 14. 남은 결정 사항
1. 전투 템포(평균 약 19초)를 더 늘릴지 → 사람 플레이 후 판단.
2. 저격 선언을 유지할지(현재 선언 방식) vs 자유 저격으로 바꿀지.
3. PvP(온라인) 도입 시점과 서버 구조.
